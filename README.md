# 공부방 회원 관리 시스템

공부방 회원 관리를 위한 웹 애플리케이션입니다.

## 기능

### 관리자 대시보드
- 총 회원 수 통계
- 평균 출석률 확인
- 미납 회원 현황
- 총 상담 수 관리
- 반별 인원 분포 차트
- 출결 현황 시각화
- 최근 상담 내역

### 회원 관리
- 회원 등록 및 수정
- 회원 목록 조회
- 검색 기능 (이름, 연락처)
- 미납 회원 필터링
- 회원 상세 정보 확인

### 기록 관리
- 진도 기록
- 상담 기록
- 출결 관리

## 시작하기

1. `index.html` 파일을 브라우저에서 엽니다.
2. 회원 등록 폼을 통해 새 회원을 추가합니다.
3. 대시보드에서 통계를 확인합니다.
4. 회원 목록에서 회원을 선택하여 상세 정보를 봅니다.

## 파일 구조

```
teamin1/
├── index.html    # 메인 HTML 파일
├── script.js     # JavaScript 로직
└── style.css     # 스타일 시트
```

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API (차트)
